## 📱 Mobile App Screens

1. **`pte_mobile_dashboard`**: iOS dynamic notch, Streak tracker, 79+ Goal card with radial readiness gauge, 4 Section cards (Speaking, Writing, Reading, Listening), and bottom tab bar.
2. **`pte_mobile_practice`**: Mobile speech practice interface with 40s timer, prompt passage, real-time waveform audio visualizer, large central record button, native speaker model audio button.
3. **`pte_mobile_score`**: Circular 84/90 score dial, enabling skills breakdown bars (Pronunciation, Fluency, Grammar, Vocabulary), word-by-word pronunciation highlights.
4. **`pte_mobile_mocktest`**: Official Pearson timed exam view for mobile with quick question palette drawer and navigation controls.
